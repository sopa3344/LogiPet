# LogiPet v1.0.0

MX Master 4와 함께 걷고 쉬며 오늘의 마우스 활동을 기록하는 XP 스타일 픽셀 동반견,
모찌의 첫 공개 배포입니다.

## 다운로드

- `LogiPet-Windows.zip` — Windows 10/11
- `LogiPet-macOS-Apple-Silicon.zip` — Apple Silicon Mac(M1 이후)
- `LogiPet-macOS-Intel.zip` — Intel Mac
- `LogiPet.lplug4` — Logi Options+ Actions Ring 플러그인

## 주요 기능

- 마우스 움직임에 맞춰 제자리에서 걷고 달리는 모찌
- 커서의 좌우 위치를 바라보는 픽셀 애니메이션
- 좌·우·휠 클릭, 휠 회전, Actions Ring 사용 횟수의 로컬 통계
- 현재 시각과 활동 상태에 맞는 XP 도우미 말풍선
- MX Master 배터리 확인
- 간식, 물, 하이파이브, 스트레칭, 낮잠 등 13개 Actions Ring 액션

설치와 권한 설정, 플레이 방법은 저장소의 README를 확인해 주세요.

## macOS 안내

macOS 앱은 GitHub Actions에서 테스트하고 빌드한 ad-hoc 서명 데모입니다.
첫 실행은 Control-클릭 후 **열기**를 선택하고, 활동 통계를 사용하려면
시스템 설정의 **개인정보 보호 및 보안 → 손쉬운 사용**에서 LogiPet을 허용해 주세요.
