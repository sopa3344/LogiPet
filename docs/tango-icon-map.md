# LogiPet Tango icon map

LogiPet uses unmodified 32×32 PNG files from the public-domain Tango Icon Theme
0.8.90. The filenames below refer to paths inside `Tango/32x32/` from the
Debian/Ubuntu package.

Source package:
`https://archive.ubuntu.com/ubuntu/pool/universe/t/tango-icon-theme/tango-icon-theme_0.8.90-11_all.deb`
